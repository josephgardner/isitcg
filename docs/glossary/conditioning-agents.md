# Conditioning Agents

**Verdict:** CG Approved with caution

These ingredients are Cationic Surfactants that can be an effective mild cleanser in a conditioner or as film-forming conditioning agents. They are water soluble, but some can build up over time.

> This page is a stub. [Edit it on GitHub](https://github.com/josephgardner/isitcg/edit/main/docs/glossary/conditioning-agents.md) to add more detail.

## Common ingredients

- Acrylamidopropyltrimonium Chloride/Acrylamide Copolymer
- Behenamidopropyl dimethylamine
- Behentrimonium chloride
- Behentrimonium methosulfate
- Benzalkonium chloride
- Cetrimonium bromide
- Cetrimonium chloride
- Cinnamidopropyltrimonium chloride
