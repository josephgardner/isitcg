# Cleansing Agents

**Verdict:** CG Approved with caution

These ingredients are cleansing agents that could potentially be drying, but are not as harsh as sulfates.

> This page is a stub. [Edit it on GitHub](https://github.com/josephgardner/isitcg/edit/main/docs/glossary/cleansing-agents.md) to add more detail.

## Common ingredients

- Cocamide DEA
- dioctyl sodium sulfosuccinate
- disodium cocoyl glutamate
- PEG-120 Methyl Glucose Dioleate
- PPG-2 Hydroxyethyl Coco/Isostearamide
- sodium cocoyl glutamate
- sodium cocoyl sarcosinate
- sodium lauroyl methyl isethionate
