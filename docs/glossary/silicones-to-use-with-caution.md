# Silicones to Use with Caution

**Verdict:** CG Approved with caution

These ingredients are partially soluble silicones to avoid, but could possibly be shampooed out with a sulfate free shampoo (may build up and need a sulfate to remove.)

- Cyclomethicone

- Cyclotetrasiloxane
- Lauryl Methicone Copolyol
- Octamethyl cyclotetrasiloxane
- Silicone Quaternium-17
